# سایت اخوان صفائی

سایت معرفی نویسنده و فروش آنلاین کتاب «دیسیپلین کار»، اثر علیرضا اخوان صفائی.

## پشته فنی
- React 18 + React Router 7
- Vite 7
- Tailwind CSS 4
- Context API برای سبد خرید (با ذخیره‌سازی در localStorage)

## اجرای پروژه
```bash
npm install
npm run dev       # اجرای محیط توسعه
npm run build     # ساخت نسخه‌ی نهایی (dist/)
npm run preview   # پیش‌نمایش نسخه‌ی build شده
```

## ساختار پوشه‌ها
```
src/
  assets/       فونت‌ها و تصاویر
  components/   کامپوننت‌های قابل استفاده مجدد (هر کدام در پوشه خودش)
  context/      CartContext (وضعیت سبد خرید)
  data/         داده‌های کتاب‌ها، نوشته‌ها و متن معرفی صفحه اصلی
  pages/        صفحات سایت (هر کدام در پوشه خودش)
  routes.jsx    نگاشت مسیرها به صفحات (lazy-loaded)
```

## سبد خرید و پرداخت
فرآیند «افزودن به سبد ← سبد خرید ← تکمیل خرید» به‌طور کامل پیاده‌سازی شده و اطلاعات سفارش
(نام، شماره تماس، آدرس) دریافت می‌شود. **این پروژه هنوز به هیچ درگاه پرداخت واقعی (مثل زرین‌پال)
یا بک‌اند سفارش متصل نیست.** نقطه‌ی اتصال در `src/pages/Checkout/Checkout.jsx` با یک کامنت
مشخص شده — کافی‌ست همان‌جا اطلاعات سفارش را به سرور خودتان ارسال کنید و کاربر را به درگاه
پرداخت هدایت کنید.
