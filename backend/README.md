# بک‌اند سایت اخوان صفائی

یک سرور ساده Node.js + Express که داده‌های سایت (مقالات، سفارش‌ها، قیمت/موجودی کتاب،
تنظیمات تماس) را نگه می‌دارد و به پنل مدیریت و سایت اصلی سرویس می‌دهد.

## اجرا

```bash
cd backend
npm install
cp .env.example .env    # در صورت نیاز مقادیر را عوض کنید
npm start                # سرور روی http://localhost:4000 بالا می‌آید
```

برای توسعه با ری‌استارت خودکار: `npm run dev`

## متغیرهای محیطی (`.env`)
| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `PORT` | پورت سرور | `4000` |
| `JWT_SECRET` | کلید امضای توکن ورود ادمین — **حتماً قبل از استفاده‌ی واقعی عوض شود** | — |
| `ADMIN_USERNAME` | نام کاربری پنل مدیریت | `admin` |
| `ADMIN_PASSWORD` | رمز عبور پنل مدیریت | `admin1403` |

## ذخیره‌سازی داده
داده‌ها در یک فایل JSON در `backend/data/db.json` نگه‌داری می‌شوند (بدون نیاز به نصب
پایگاه‌داده‌ی جداگانه). این فایل به‌صورت خودکار در اولین اجرا با محتوای اولیه ساخته
می‌شود. برای استقرار واقعی روی هاست، این فایل باید در یک مسیر دائمی (persistent disk)
قرار بگیرد، وگرنه با هر deploy جدید داده‌ها پاک می‌شوند.

## مسیرهای API
- `POST /api/auth/login` — ورود ادمین، برمی‌گرداند `{ token }`
- `GET /api/articles` , `GET /api/articles/:id` — عمومی
- `POST/PUT/DELETE /api/articles(/:id)` — نیاز به `Authorization: Bearer <token>`
- `GET /api/books` — بازگرداندن override قیمت/موجودی (عمومی)
- `PUT /api/books/:id` — تغییر قیمت/موجودی (ادمین)
- `POST /api/orders` — ثبت سفارش (عمومی، از صفحه‌ی checkout استفاده می‌شود)
- `GET /api/orders` , `PATCH /api/orders/:id/status` — ادمین
- `GET /api/settings` — عمومی، `PUT /api/settings` — ادمین

## نکته‌ی مهم درباره‌ی پرداخت
این بک‌اند سفارش‌ها را ثبت می‌کند اما به هیچ درگاه پرداخت واقعی (زرین‌پال و…) وصل
نیست. نقطه‌ی اتصال در فرانت‌اند، فایل `src/pages/Checkout/Checkout.jsx`، با کامنت
مشخص شده است.
