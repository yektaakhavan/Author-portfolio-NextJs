# سایت اخوان صفائی — پروژه کامل (فرانت‌اند + بک‌اند)

## ساختار پروژه
```
Author-portfolio/   سایت (React + Vite + Tailwind)
backend/             سرور API (Node.js + Express)
```

## اجرا (محیط توسعه)
دو سرور باید همزمان اجرا شوند — هرکدام در یک ترمینال جدا:

```bash
# ترمینال ۱ — بک‌اند
cd backend
npm install
npm start                # http://localhost:4000

# ترمینال ۲ — فرانت‌اند
cd Author-portfolio
npm install
npm run dev               # http://localhost:5173
```

فرانت‌اند به‌صورت پیش‌فرض با `http://localhost:4000/api` صحبت می‌کند. برای تغییر آدرس
(مثلاً بعد از دیپلوی بک‌اند روی یک سرور)، در پوشه‌ی `Author-portfolio` فایل `.env` بسازید:
```
VITE_API_URL=https://api.yourdomain.com/api
```

## پنل مدیریت
آدرس: `/admin` — نام کاربری و رمز پیش‌فرض در `backend/.env.example` — **قبل از انتشار
واقعی سایت حتماً عوض شود.**

امکانات پنل:
- سفارش‌ها (مشاهده و تغییر وضعیت)
- مدیریت کتاب (قیمت و موجودی)
- مقالات (افزودن، ویرایش، حذف — همراه با گالری تصویر آماده)
- تنظیمات سایت (شماره تماس، ایمیل، متن پشتیبانی)

این پنل حالا از طریق بک‌اند واقعی کار می‌کند، یعنی تغییراتی که اینجا اعمال می‌شود برای
همه‌ی بازدیدکننده‌های سایت (نه فقط مرورگر شما) دیده می‌شود.

## استقرار (Deploy)
- **بک‌اند**: هر سروری که Node.js اجرا کند (مثل یک VPS ساده، Railway، Render). فایل
  `backend/data/db.json` باید روی یک دیسک دائمی ذخیره شود.
- **فرانت‌اند**: خروجی `npm run build` یک سایت استاتیک است؛ روی هر هاست استاتیک
  (Vercel، Netlify، سرور خودتان) قابل انتشار است — فقط باید `VITE_API_URL` را به آدرس
  واقعی بک‌اند تنظیم کنید.

## پرداخت آنلاین
فرآیند خرید (افزودن به سبد → checkout → ثبت سفارش) کامل است و سفارش‌ها در بک‌اند ذخیره
می‌شوند، اما به هیچ درگاه پرداخت واقعی وصل نیست — این بخش نیاز به قرارداد با یک درگاه
(مثل زرین‌پال) و افزودن آن به بک‌اند دارد. جزئیات بیشتر در `backend/README.md`.
